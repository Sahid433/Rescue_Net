# RescueNet – Intelligent Disaster Management & Emergency Response System

A full-stack B.Tech CSE project prototype built with Python Flask, SQLite, HTML, CSS and JavaScript.

## Features
- Role-based demo login (Admin, Field Team, Citizen)
- Operations dashboard with KPIs and charts
- Emergency incident reporting
- Rule-based explainable priority/risk assessment
- Incident search, filtering, assignment and status workflow
- Rescue team directory and availability
- Relief resource inventory with quantity updates
- Shelter capacity tracking
- Incident map using Leaflet + OpenStreetMap
- Analytics dashboard and CSV export
- SQLite database with demo seed data

## Run on Windows
1. Install Python 3.10 or newer.
2. Extract the ZIP and open the `RescueNet` folder in VS Code.
3. Open terminal and run:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python app.py
   ```
4. Open `http://127.0.0.1:5000`.

## Important academic note
This is a functional academic prototype, not a production emergency dispatch system. The priority score is generated by transparent keyword/person-count rules; it is not a validated AI model and must not be used for real emergency triage. Map markers are based on demo coordinates unless a reporter supplies coordinates. The map and chart libraries load from public CDNs, so those visual elements require internet access.
